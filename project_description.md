# Project Description — SAP AI Learning Agent

Design and progressively build an internal **SAP AI Learning Agent** for LTM SAP BASIS freshers/trainees. The system should transform approved SAP technical sources — including TADMs, SAP Help / HANA administration documentation and other approved documents — into a grounded, interactive learning experience. Learners should be able to follow structured course modules, ask contextual questions, receive beginner-friendly or deep technical explanations with mandatory citations, explore interactive diagrams, use voice narration, complete knowledge checks, and eventually perform selected controlled exercises against an SAP training system.

The solution contains two primary agent workflows: a **learner-facing Main AI Agent** for contextual teaching and Q&A, and a **Course Builder Agent** that generates structured learning-module drafts from a topic using the same SAP knowledge layer and requires admin review before publication. SAP Notes / KBAs are treated as situational, on-demand knowledge through a dedicated retrieval tool. The architecture should remain modular and failure-driven: add complexity only when a concrete requirement or measured failure justifies it.
